# 视觉语汇对照表

把风格词落成可检查的范围；先概念，后数值。

## 语汇 → 可写字段

| 风格词（例） | 优先写清的概念 | 可映射方向（示例，需创作者确认） |
| --- | --- | --- |
| 孤独 | 负空间大、主体小、冷色 | 降低饱和；`camera` 更慢；粒子更稀 |
| 释放 | 空间打开、边缘变亮 | 饱和回升；镜头微推；密度上升 |
| 压迫 | 主体被框住、高对比 | 收紧构图；提高 `density` 映射；少留白 |
| 呼吸感 | 有停顿、循环可接 | 检查 preview 循环接缝；避免闪烁 |

## 写作检查清单

- [ ] 主体是什么、负空间在哪
- [ ] 色温与材质一句话描述
- [ ] 运动节奏：跟拍 / 漂浮 / 节拍切割
- [ ] `visual` 与 `orchestrate` 是否可复现（含种子/范围）
- [ ] `muse preview` 下小屏是否仍可读

## 注意

外部生成素材只作输入；编排与校验用 Muse。视频容器支持范围不明时，先确认再引用路径。

## 复用对象的适配检查

- 歌词卡/字效以稳定语义 key 绑定文字；源演唱 cue 与译文显示分开。
- 选择资源 → shaping/文字测量 → 布局 → 动画/镜头变换 → 绘制。局部响应函数的输入/输出明确，不靠组件顺序争夺字段。
- 锚点、安全区、焦点和换行应适配实际 viewport；长译文需要局部布局或分段，不能无限缩字。
- 端口传常规参数，单基底派生或实例覆盖表达艺术差异；基底/覆盖来源可查，悬空目标不可忽略。
- 纯帧函数显式接收时间与上下文；模拟用固定步长、显式状态和 seed。不要让语言切换偶然重启无关模拟。
- 未实现的组件/VM 绑定只可作为标明的设计示意，不能声称 preview 已执行该效果。
