# 创作简报模板

生成 `.muse` 前只填会改变方案的字段；空项可留空。

## 必问（会改路径）

| 字段 | 填写 |
| --- | --- |
| 作品目的 | 表达 / 解释 / 记录 / 娱乐 / 教学 / 推广 |
| 形式 | 音乐 / 播客 / 科普 / 短视频 / 电影 / 游戏过场 / 抽象视觉 |
| 时长与画幅 | 总时长；9:16 / 1:1 / 16:9 / 纯音频 |
| 受众与场景 | 年龄/知识；是否静音观看；手机或大屏 |
| 交付物 | preview / MIDI / MusicXML / WAV / MP3 / MP4（若可用） |

## 可选加深

- 情绪弧：开始 → 转折 → 峰值 → 结束
- 声音：人声 / 旋律 / 音乐床 / 留白 / 响度底线
- 视觉：主体 / 色彩 / 构图 / 镜头 / 字幕 / 图表 / 粒子
- 约束：品牌、事实、版权、素材格式、截止时间

## 改写示例

把抽象词改成可观察结果：

- 差：“副歌要炸”
- 好：“副歌前 4 小节张力上升；切镜更密；饱和度提高；禁止闪白”

路由提示：形式一经确认，立即转交对应 skill，不要在本简报里写完整脚本。

## 需要多语言、多画幅或复用时

- 分别记录演唱/声音语言与画面文字语言，不按地域自动改音轨。
- 区分观看尺寸与剪辑意图：竖屏可完整，短片可横屏。
- 标出共享角色、镜头、歌词卡、声音与时间图；语言和 viewport 由组件绑定/布局适配，个别艺术差异保留为实例覆盖或派生。
- 每个实际发行目标选择入口、上下文和 outputs；不强制复制六套工程，也不默认全部排列组合。
- 明确用户要求的是设计、写可执行源还是交付；设计不授权实现新语言机制，准备交付不授权外部发布。
