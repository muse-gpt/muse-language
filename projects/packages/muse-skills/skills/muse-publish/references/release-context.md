# 多版本发行的共享与验收

## 任务身份

每个实际目标记录：入口、显示 locale、声音来源、viewport/安全区、剪辑、产物和输出路径。字段按任务需要选择，不要求填固定矩阵或生成所有组合。画面文字语言不推导演唱/配音语言。

Prefab 保存共享对象/组件，实例传参数和局部覆盖；PrefabVariant 只表达艺术性差异。ReleaseJob 是发行选择，可以复用同一 scene。日文/中文/英文和横竖六个视频是某次发行选择，不是语言内建六类模板。

这些是创作组织概念，执行前核实工具支持。只有当前版本确实提供 prefab/job 命令才能调用；设计稿不能当成功输出或运行能力证据。

## 本地化

- 歌词、标题、叙事字、画面标识、stamp、尾卡、封面和字幕有稳定语义 key；检查烘焙图片里的原文，必要时拆字层或选择本地化图片。
- 源演唱 cue 保持共同时钟。中文/英文译文通过 CueId 关联，默认整句或审定短语高亮；需要译文逐词高亮时提供明确多对多对齐。
- 专名、署名与原文艺术字按显式保留策略处理。缺必须翻译的项不能静默回退，预览回退须标识。
- 字体资产/版本、字形覆盖、断行、最小字级、正文停留时长与安全区按实际 locale 和 viewport 验收。

## 剪辑与布局

短版与竖屏独立选择。短版从源取用、重排或重复镜头时，音轨、画面、歌词和事件共享源到输出时间映射；重复片段使用不同实例身份。

布局根据主体焦点和实际文字尺寸求值；先测量再布局，最后施加动画。局部覆盖保留来源，基底更新传播到未覆盖字段；出现悬空目标、类型变更、属性双写时不能静默忽略。

## 交付证据

逐目标记录实际文件、帧数、时长、画幅、声音来源、字幕语言和关键预览帧。验证 preview 与成片在同一时间对应，尤其是截断范围、剪辑点与文字切换。

使用工具实际提供的清单记录源、资源、字体、剪辑、上下文和后端版本；尚无该能力时用户交付说明可以记录已知信息，但不能伪造工具 manifest。

明确隔离每项产物路径。清理仅限确切已授权且归属可核对的生成物，不删除共享资产或基底 prefab。准备交付不自动授权上传、消息发送或外部发布。
