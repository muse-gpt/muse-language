# 播客与声音叙事

先整理听众、节目承诺、嘉宾关系和章节顺序。声音优先：清晰人声、自然停顿和可理解的音乐层比视觉装饰更重要。

用 `timeline` 表示章节，用 `intent` 表示亲密、紧张、调查或释疑，用 `music` 定义音乐床和密度，用 `orchestrate` 规定音乐何时让位于人声。需要视频版时，再添加低干扰的背景、字幕安全区和节拍驱动的视觉变化。

预览必须检查人声是否被音乐掩盖、片头是否过长、章节转场是否可感知。交付 WAV/MP3 与章节清单；不要把没有实际视频编码的 PNG/WAV 目录宣称为 MP4。

需要规划节目结构时读取 [audio-brief.md](references/audio-brief.md)。
