# 场景简报模板

每个场景一张短表，再映射到 `act`。

## 场景卡

| 字段 | 内容 |
| --- | --- |
| 场景名 |  |
| 对应 act / 小节 |  |
| 人物欲望 | 这一场想得到什么 |
| 障碍 / 转折 | 什么改变了局势 |
| 观众应理解的信息 | 空间 / 视线 / 因果 |
| 情绪（intent） | 一句话 |
| 声音重点 | 动机、留白、对白层 |
| 画面重点 | 主体、景别倾向、运动 |
| 硬约束 | 如：禁止闪白、保留负空间 |

## 映射到 Muse

1. `timeline`：`act <name> : start..end`
2. `intent`：该场情绪
3. `orchestrate`：能量峰、转场策略、硬约束列表
4. `music` / `visual`：只写服务叙事的可执行项
5. `muse check` → `muse preview` 后按场次验收

参考片名只拆成可观察倾向（色彩、运动、剪辑密度），不写成伪参数。
