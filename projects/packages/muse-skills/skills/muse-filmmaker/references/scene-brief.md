# 场景简报模板

每个场景一张短表，再映射到 `act`。

## 场景卡

| 字段 | 内容 |
| --- | --- |
| 场景名 |  |
| 对应 act / 时间 | 起止和单位；与歌曲共用时钟 |
| 人物欲望 | 这一场想得到什么 |
| 障碍 / 转折 | 什么改变了局势 |
| 观众应理解的信息 | 空间 / 视线 / 因果 |
| 情绪（intent） | 一句话 |
| 声音重点 | 动机、留白、对白层 |
| 画面重点 | 主体、景别倾向、运动 |
| 硬约束 | 如：禁止闪白、保留负空间 |

## 映射到 Muse

1. `timeline`：`act <name> : start..end`
2. `intent`：该场情绪
3. `orchestrate`：能量峰、转场策略、硬约束列表
4. `music` / `visual`：只写服务叙事的可执行项
5. `muse check` → `muse preview` 后按场次验收

参考片名只拆成可观察倾向（色彩、运动、剪辑密度），不写成伪参数。

## 对象复用与局部差异

按需要记录角色、道具、歌词卡和镜头的共享对象及参数端口。引用 prefab 的实例保留稳定 id；嵌套对象通过明确端口连接。画面上相同的结构不必为了语言或分辨率另抄完整 scene。

常规参数传端口，个别长译文或镜头位置可实例覆盖，真正结构变化可单基底派生。记录覆盖目标、值/绑定和来源；基底更新传播到未覆盖字段，删除或改型目标须诊断。

本地化绑定根据明确 locale 选择语义文本/图片，布局在测量后按可用宽度求值。动画用独立通道或明确 offset，不与布局抢最终属性。字体与图中文字均要检查。

短片可独立编排共享镜头，不强制继承全长剪辑；声音、歌词和事件共同映射。prefab/instance 等表示创作概念，可执行语法须核实当前工具支持。
