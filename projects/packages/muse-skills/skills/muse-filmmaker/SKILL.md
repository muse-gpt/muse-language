# 影视叙事工作流

从 logline、人物欲望和场景转折开始。把“导演意图”保留在 `intent`，把跨部门协调写进 `orchestrate`；不要一开始就用 FOV、速度和剪辑参数替代叙事判断。

## 从场景到 Muse

1. 每个 `act` 对应一个可描述的情绪或叙事动作，并明确起止小节。
2. 为场景建立视觉主元素、镜头目标、运动、景别和转场的可执行规则。
3. 为音乐指定动机、调性、密度和留白；让声音变化服务于叙事转折。
4. 在 `orchestrate` 中写能量峰、情绪转折和硬约束，例如不使用闪白或保留负空间。
5. 运行 `muse check` 与 `muse preview`，逐段检查节奏是否让观众理解空间、视线和因果。

不要把参考导演或影片名直接当作可执行风格参数；把参考拆成色彩、构图、运动、光线、声音和剪辑倾向，并让创作者确认。

需要展开场景时读取 [scene-brief.md](references/scene-brief.md)。
