# 影视叙事工作流

## 受众

导演、剪辑、MV 与纪录片创作者，以及需要镜头语言组织时间线的人。

## 何时使用

- 有 logline、人物欲望、场景转折或镜头计划。
- 音乐与画面服务于叙事因果，而不是纯抽象视觉或纯短视频钩子。

纯主题作曲 → `muse-composer`；关卡状态机 → `muse-game-cinematic`。

## 工作流

1. 从 logline、人物欲望与场景转折开始；复杂场景用 [scene-brief.md](references/scene-brief.md)。
2. 每个 `act` 对应一个可描述的情绪或叙事动作，并写清起止小节（`timeline`）。
3. `intent` 保留导演意图；`orchestrate` 写跨部门规则（能量峰、硬约束如“不使用闪白”、转场策略）。
4. `music` 服务转折：动机、调性、密度与留白；`visual` 写主体、景别倾向、运动与转场可执行描述。
5. `tempo` 对齐叙事加速/减速，而非堆参数。
6. `muse check` → `muse preview`：逐段检查观众能否理解空间、视线与因果；交付交给 `muse-publish`。

## 硬约束

- 不要一上来用 FOV、数值速度替代叙事判断。
- 参考导演/片名不能直接当可执行风格参数；拆成色彩、构图、运动、光线、声音与剪辑倾向，并让创作者确认。
- 新稿用 `orchestrate`，不要用旧的 `directing` 写法冒充新合同。
- 不把预览目录说成已完成成片；失败如实报告。
