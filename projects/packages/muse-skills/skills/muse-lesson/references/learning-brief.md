# 学习简报模板

先写目标与验收，再拆 `act`。

## 课时目标

| 字段 | 内容 |
| --- | --- |
| 学习目标 | 学完能做什么（可观察） |
| 完成标准 | 如何判断学会 |
| 学习者画像 | 初学 / 有背景；观看设备 |
| 无声需求 | 是否必须靠字幕学完 |

## 概念序列（每行一个 act）

| act | 新概念 | 例子 | 停顿/思考点 | 检查理解方式 |
| --- | --- | --- | --- | --- |
| 1 |  |  |  | 提问 / 对照 / 小练习 |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

规则：一行只引入一个新概念；缺前置知识就插入短 act。

## Muse 映射

- `intent`：好奇 → 澄清 → 练习 → 掌握
- `orchestrate`：信息密度上限、视觉强调点
- `visual`：标注、流程、单位与图例
- 验收：`muse check` → `muse preview`（初学版 / 有背景版 / 无声版各看一遍）
