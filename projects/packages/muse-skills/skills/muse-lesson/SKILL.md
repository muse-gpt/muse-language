# 教学视频工作流

## 受众

教师、课程作者、企业培训者。

## 何时使用

- 有明确学习目标与可观察的完成标准。
- 需要解释 → 例子 → 停顿 → 检查理解的节奏。

偏大众科普传播 → `muse-science-video`；纯短视频获客 → `muse-short-video`。

## 工作流

1. 写学习目标与验收标准；完整段落用 [learning-brief.md](references/learning-brief.md)。
2. 每个 `act` 只引入一个新概念，并安排：解释、例子、停顿、检查理解。
3. `intent`：好奇 / 澄清 / 练习 / 掌握；`orchestrate` 控制信息密度与视觉强调。
4. `timeline` / `tempo` 给思考留白；`visual` 做标注、流程、时间线或实验示意；需要配乐床时用低密度 `music`。
5. 分别为初学者、有背景学习者、无声观看检查字幕、单位、图例与色盲可读性。
6. `muse check` → `muse preview`；交付与多平台版本交给 `muse-publish`。

## 硬约束

- 不先追求华丽画面；概念跳跃不能用快剪掩盖。
- 发现前置知识缺失时，新增短 `act` 或旁路解释，不要假装“已经讲过”。
- 字幕与单位错误视为内容错误，不是后期小事。
- 不伪造测验成绩或学习效果数据。
