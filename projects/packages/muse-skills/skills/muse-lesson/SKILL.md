# 教学视频工作流

先写学习目标和可观察的完成标准，不先追求华丽画面。每个 `act` 只引入一个新概念，并为它安排解释、例子、停顿和检查理解的机会。

用 `intent` 表达好奇、澄清、练习和掌握；用 `orchestrate` 控制信息密度和视觉强调；用 `visual` 做标注、流程、时间线或实验示意。字幕、单位、图例和色盲可读性属于内容正确性的一部分。

分别为初学者、已有背景的学习者和无声观看场景检查预览。不要用快速剪辑掩盖概念跳跃；发现前置知识缺失时，新增一个短 act 或提供旁路解释。

需要设计完整教学段落时读取 [learning-brief.md](references/learning-brief.md)。
