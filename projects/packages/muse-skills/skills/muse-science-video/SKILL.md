# 科普视频工作流

## 受众

科普作者、科学传播者、需要事实边界清晰的知识型视频创作者。

## 何时使用

- 目标是解释概念、实验、历史或技术原理。
- 需要“事实 / 推断 / 争议”分层，而不是纯娱乐短片。

纯课堂教学目标 → `muse-lesson`；纯钩子留存短视频 → `muse-short-video` 后再嵌科普结构。

## 工作流

1. 写一句核心问题 + 目标受众知识水平；维护证据简报，见 [evidence-brief.md](references/evidence-brief.md)。
2. 将答案拆成 3–7 个 `act`，每段只承担一个概念。
3. 为每段准备：叙述要点、可见证据、比喻、常见误解澄清。
4. 用 `timeline` / `tempo` 控制信息密度；难概念给停顿，不用快剪代替解释。
5. 用 `intent` 表达好奇 / 澄清 / 警示；用 `orchestrate` 把重点词映射到画面强调；用 `visual` 做图表、示意、字幕安全区。
6. `muse init`（如需）→ 写 `.muse` → `muse check` → `muse preview`；成片交付交给 `muse-publish`。

## 硬约束

- 已证实事实、合理推断、争议观点必须分开写；缺引用就标“待核查”，不编造数据、原话或“科学家都认为”。
- AI 生成画面只能作解释辅助，不得伪装成真实观测证据。
- 不夸大结论换戏剧性；单位、日期、不确定性写在旁注或交付说明里。
- 预览失败或素材不支持时说明替代格式；不要把 PNG/WAV 预览宣称为已发布科普成片。
