# @muse-gpt/muse-win32-x64

Prebuilt native `muse` binary for Windows x64. **Not a public import target.**

Pulled automatically when installing `@muse-gpt/muse` on matching hosts.

## Example

```bash
muse doctor
```

Depend on [`@muse-gpt/muse`](https://www.npmjs.com/package/@muse-gpt/muse) only; this package supplies the executable behind the scenes.
