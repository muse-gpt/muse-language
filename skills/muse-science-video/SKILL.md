# 科普视频工作流

先建立“事实边界”，再设计节奏。将内容分成：已证实事实、合理推断、争议观点和需要引用的数字；不要为了戏剧性夸大结论。

## 结构

1. 写出一句观众能理解的核心问题和目标年龄/知识水平。
2. 将答案拆成 3 至 7 个段落，每段只承担一个概念。
3. 为每段设计叙述、可见证据、比喻和误解澄清。
4. 用 `timeline` 和 `tempo` 控制信息密度；复杂概念给停顿，不用快速剪辑代替解释。
5. 用 `visual` 表达图像、图表、粒子或镜头运动，用 `orchestrate` 把重点词和张力映射到画面强调。

## 可信度检查

在脚本旁维护来源、发布日期、测量单位和不确定性。引用缺失时标记待核查，不凭空生成实验数据、人物原话或“科学家都认为”。预览时检查字幕安全区、图表标签、颜色可读性和语速。

把最终 Muse 文件、来源清单和发布说明分开交付；AI 生成的视觉只作为解释辅助，不能伪装成真实观测证据。

需要逐条核查来源时读取 [evidence-brief.md](references/evidence-brief.md)。
